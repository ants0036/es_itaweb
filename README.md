# es_itaweb
ES Itaweb!! is a web app for collectors to track pieces of Ensemble Stars goods. It uses Cloudinary & Supabase to track releases and user data. 

Website framework: [Next.js](https://nextjs.org/)
Database management & Authentication: [Supabase](https://supabase.com/)
Image management: [Next Cloudinary](https://tailwindcss.com/docs)
Styling: [Tailwind CSS](http://a.com)
